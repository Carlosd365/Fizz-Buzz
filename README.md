# Fizz-Buzz
## 📋 Description

The program prints numbers from **1 to 100** with the following rules:

- If a number is a **multiple of 3**, it prints `fizz`.
- If a number is a **multiple of 5**, it prints `buzz`.
- If a number is a **multiple of both 3 and 5**, it prints `fizz-buzz`.
- Otherwise, it prints the number itself.
